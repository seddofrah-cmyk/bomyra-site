# BOMYRA Website

Official bilingual public website for **BOMYRA — AI Chat Saver & Exporter**.

- **Live website:** https://seddofrah-cmyk.github.io/bomyra-site/
- **Privacy & Data Notice:** https://seddofrah-cmyk.github.io/bomyra-site/privacy.html
- **Source repository:** https://github.com/seddofrah-cmyk/bomyra-site

This repository contains the public-facing website only. It does **not** contain the BOMYRA Chrome extension source code, installation package, API keys, credentials, or private project records.

## How it is published

GitHub Pages is configured to deploy from the `main` branch and repository root (`/(root)`). GitHub Pages builds the Markdown pages with Jekyll and the Minima theme.

## Main files

- `index.md` — bilingual English/Arabic product homepage.
- `privacy.md` — complete bilingual privacy and data notice; rendered at `/privacy.html`.
- `_config.yml` — Jekyll and Minima site configuration.
- `assets/css/style.scss` — BOMYRA color palette and site styling.
- `PRIVACY.md` — source copy of the product privacy notice.

- Add a custom domain only after ownership and DNS are confirmed.

## Product facts

The site describes BOMYRA as a browser extension for ChatGPT, Claude, and Google Gemini. It explains selective message capture, portable exports, optional cloud AI summaries, and local model workflows. Pricing and public availability are not represented as finalized.
