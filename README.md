# BOMYRA Website

Official bilingual website for **BOMYRA — AI Chat Saver & Exporter**.

This repository contains only the public marketing website and privacy notice. It does not contain the Chrome extension source code.

## Publish with GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for GitHub Pages to finish deploying. The expected URL is https://seddofrah-cmyk.github.io/bomyra-site/ .

## Files

- `index.html` — bilingual product landing page.
- `privacy.html` — product privacy and data notice.
- `styles.css` and `script.js` — site styles and language/menu behavior.
