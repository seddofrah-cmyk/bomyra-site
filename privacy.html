Overview/h3> p>BOMYRA runs in your browser on supported chat websites. Message selection, processing, and ordinary exports are performed locally unless you explicitly choose a feature that contacts the relevant chat platform, media host, local model server, or cloud AI provider. The extension package has no developer-operated server that relays conversation content for AI summaries./p> h3>2. Information stored in your browser/h3> p>The extension uses code>chrome.storage.local/code> for preferences (such as language, provider selection, model names, custom summary prompts, and an optional remote selectors URL), an optional Anthropic workspace ID, provider-consent flags and timestamps, and a local archive of up to 50 entries. Each archive entry stores a shortened title, operation type/template, date, and up to approximately 500 characters of saved output or content. p>Gemini, OpenAI, and Anthropic API keys, plus an optional local-model authentication token, are stored in code>chrome.storage.session/code> rather than persistent local storage. Chrome clears this session storage when the browser restarts or the extension is disabled, reloaded, or updated, so credentials must be entered again after those events. This reduces how long credentials remain on the device; it is code>not encryption/code>. Malware or compromised extension code may still access a credential while the extension is active. Persistent preferences and archive data are also not end-to-end encrypted by the extension. Do not use API keys on shared or untrusted devices. p>When you select generated ChatGPT images for export, image bytes may be cached temporarily in IndexedDB under the chat website's own origin so they remain available after page elements disappear during scrolling. Deselecting an image removes its record. The delete-all-data control asks open chat tabs to clear media databases and records cleanup work for supported origins that are not open; cleanup may remain pending until you visit that site again. This cache is not sent to summary providers. h3>3. What leaves your device/h3> p>code>Cloud AI summaries (Gemini, OpenAI, Claude):/code> these occur only after you enable a provider, accept its separate consent, and request a cloud summary. Selected message text and your custom summarization prompt are sent directly from the browser to the chosen provider API; your API key is sent for authentication. If configured, the optional Anthropic workspace ID is sent only with Claude requests. Images and file attachments are not included in cloud summary requests. You can cancel an active request. The extension may retry certain explicit rate-limit or service-overload responses a limited number of times, while avoiding ambiguous failures that could duplicate provider work. Each provider processes submitted content under its own terms, account type, and settings; BOMYRA cannot control provider retention, human review, or model-training practices. p>code>Local model summaries:/code> selected message text is sent to the loopback API server you configured (code>localhost/code>, code>127.0.0.1/code>, or code>::1/code>). The local-provider path rejects non-loopback URLs and does not automatically fall back to a cloud provider. Ollama context length (code>num_ctx/code>) is configurable from 2,048 to 262,144 tokens (default 8,192); larger values may increase local memory use. The local model runtime is separate software and may maintain its own logs or data. p>code>Chat-site retrieval:/code> Select All flows may make requests to the currently open chat platform using your signed-in browser session to retrieve conversation data. For manually selected ChatGPT messages, if creation times are not available in the page, PDF export may make a same-origin lookup to obtain source-provided times. On ChatGPT, the extension may read the short-lived code>accessToken/code> returned by the same-origin code>/api/auth/session/code> endpoint and use it only for same-origin conversation API requests. The token remains in active-operation memory; this path does not save it in extension storage or send it to another host. If a stable message match and valid source time are unavailable, the timestamp is omitted. p>code>Manual-selection metadata (ChatGPT and Claude):/code> for manual-selection exports, the extension may request same-origin conversation metadata from the currently open ChatGPT or Claude website using the browser's existing signed-in session. On ChatGPT, a short-lived token may be read from code>/api/auth/session/code> and used only for same-origin requests. On Claude, the current conversation may be requested from code>/api/organizations/{organization_id}/chat_conversations/{conversation_id}/code> using the current conversation and organization identifiers. Responses are analyzed locally to match message IDs, text, timestamps, and media references. If source metadata cannot be matched reliably, BOMYRA does not invent timestamps or associations. These requests go to the relevant chat platform and are subject to that platform's terms and privacy policy. p>code>ChatGPT generated-image discovery:/code> the extension reads browser-provided Resource Timing entries on the current page. It considers only completed same-origin fetch/XHR entries for ChatGPT's Estuary content path and retains the opaque file ID and timing order. It does not read response bodies through Resource Timing, request those URLs, or send these IDs/timing entries to cloud summary providers. p>code>Images and attachments during export:/code> when you choose an export that includes media, the extension may fetch images or files from the chat platform or its media hosts and save them into the export on your device. This media is not included in cloud summary requests by this feature. Unsupported attachments may be listed by name or retained as links, depending on what the page exposes. p>code>Optional remote selectors:/code> if you enter a selectors URL, Chrome asks you to grant optional host access to that exact HTTPS origin before the extension downloads it. The request omits credentials and rejects redirects; only a JSON response up to 256 KiB is accepted. The host can observe the request, but conversation text and chat cookies are not sent with it. The downloaded file is treated as data, validated, and not executed as code. h3>4. Local archive and your controls/h3> p>The local archive is limited to 50 entries and stores up to approximately 500 characters of content per entry. You can disable cloud providers, revoke saved cloud consents, delete the local archive, or delete all extension data in Settings → Privacy & Data. Deleting all extension data removes extension settings, stored API keys/tokens, archive entries, provider enablement, and consent flags from this browser profile. It does not delete exported files already downloaded, chat-site data, provider-side data, browser history/download records, or local model runtime logs. Uninstalling the extension removes its extension storage according to Chrome's behavior. h3>5. Permissions and network destinations/h3> p>The extension uses Chrome storage for settings and the local archive; supported chat-site access for message selection and retrieval; media-host access for exports that include images or files; provider API access for explicitly requested cloud summaries; and loopback access for local model discovery and summarization.
